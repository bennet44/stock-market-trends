# 美股／台股分析師看板

以資料分析師視角打造的美股、台股互動看板，使用 [Streamlit](https://streamlit.io/) + [yfinance](https://github.com/ranaroussi/yfinance) 免費資料。

## 功能

- **市場切換**：頁面最上方提供「美股／台股」切換鍵，切換後三個分頁的預設代號、可選股票範圍與「全部」選項皆會對應切換；台股範圍包含 ETF 及個股（清單為內建精選名單，代碼會自動補上 Yahoo Finance 所需的 `.TW` 後綴）。
- **價格、技術指標與基本面**（單一股票）：K 線圖（台股紅漲綠跌、美股綠漲紅跌，背景皆為白底）、SMA5/10/20 與布林通道（皆為輔助線、不額外填色，圖例置於圖表上方以放大繪圖區）、RSI、MACD、KD 隨機指標、成交量，與該股票的基本面財務（P/E、P/B、EPS、營收/盈餘成長率、ROE、淨利率、股息率），分頁內輸入股票代號（美股預設 AAPL，台股預設 2330）與時間範圍即可連動更新；可自行輸入「勝率 (%)」，系統會依過去 5 個交易日的歷史報酬率分布反推對應漲跌幅，估算建議買入價（逢低承接）與建議賣出價（目標停利），僅供參考非投資建議。頁面最下方附上該股票近 4 天（例如 6/17-6/20）的相關新聞，整合多個來源：Google News RSS（中文，所有市場皆有）；美股額外加上 Reuters（透過 Google News 限定 site:reuters.com）與 SEC EDGAR 申報文件（官方 API，含 8-K/10-Q 等表單連結）；台股額外加上 TWSE 證交所新聞（官方 open data，依股票代號／公司名稱比對標題）與 MOPS 公開資訊觀測站重大訊息（MOPS 無公開查詢 API，透過 Google News 限定 site:mops.twse.com.tw 搜尋取得，屬最佳努力性質，不保證每檔個股都能查到）
- **多股比較、相關性與風險統計**：分頁內輸入逗號分隔的股票代號（美股預設 `AAPL, OKLO`，留空代表全部 S&P 500 成分股；台股預設 `2330, 0050`，留空代表全部台股觀察清單）與時間範圍，同時查看累積報酬比較、日報酬相關係數矩陣（熱力圖）、年化報酬率／年化波動率／Sharpe Ratio／最大回撤／VaR 與日報酬分布
- **買賣建議**：分頁內可設定時間範圍、勝率 (%) 與建議買賣標的數量 (Top N，可選 1/5/10/15，預設 5)。美股篩選範圍為「美股交易量前 30 大（觀察名單）」與「S&P 500 成分股」的聯集，台股篩選範圍為內建台股觀察清單（含 ETF 及個股），以基金經理人角度綜合期間報酬率、Sharpe Ratio（無風險利率採固定年化 4%）、價格趨勢、估值水準、近幾日中文新聞情緒（標題關鍵字判斷）計算評分，列出建議買入／賣出的前 N 項；買入／賣出價依設定勝率反推各標的歷史報酬率分布估算目標價，並列出對應的「獲利%」，表格各欄位皆可點選表頭排序，最後一欄附上「原因說明」標示該標的進入買入／賣出名單的主要驅動因子
- **FCN風險評估**：針對股權連結型定期配息票券（FCN）的特定條款做風險評估。可設定「標的數量」（1~5 個）並以逗號分隔輸入對應數量的股票代號；標的數量大於 1 時視為「worst-of」組合票券，任一標的觸及下限價即視為觸及、須全部標的都達到提前出場價才會提前出場。輸入「投資時間（個X月）」「執行價 STRIKE(%)」「提前出場 KO(%)」「下限價 KI(%)」「年化收益率(%)」與 KI 觀察方式（到期觀察／每日觀察）後，以標的近 N 個月（N＝投資時間）歷史日報酬計算年化波動率與（多標的時）相關係數，再用蒙地卡羅模擬（幾何布朗運動／相關常態分配）評估提前出場機率、平均出場月數、本金虧損機率與報酬分布（期望報酬、5% 最差情境報酬），並列出假設無風險利率下的「風險中性參考年化收益率」供與您輸入的年化收益率比較。「單筆試算」另可輸入「投資日期」，系統會取該日期（或之前最近交易日）的實際收盤價，換算出對應的執行價 STRIKE／下限價 KI／提前出場 KO 實際金額，方便對照手上真實的條款單。模型為簡化估算（固定波動率與相關性、不含信用風險與手續費），僅供研究參考，非投資建議或實際報價。
- **存股區**：與買賣建議採不同公式的長期持有觀點，權重集中在殖利率、配息穩定性、填息率（除息缺口 60 個交易日內回補的比例）與基本面，風險調整報酬改用 Sortino（只懲罰下跌波動）取代 Sharpe，統計期間／持有天數僅提供中長期選項，定位為存股／逢低布局參考而非短線進出；可選擇套用「今年配息殖利率前N高 ∩ 填息率前N高」的候選範圍篩選。
- **買賣建議個股資訊頁的建議買賣價格參考**：統計視窗會依所選持有天數自動延長（約 1 年～10 年），確保長天期持有仍有足夠的前瞻報酬樣本可估算目標價與命中機率，不會因視窗太短而顯示「資料不足」。
- **設定值自動記憶**：所有分頁的輸入欄位（股票代號、時間範圍、各種參數）會自動存進瀏覽器的 localStorage，下次用同一個瀏覽器打開網頁時會自動帶回上次的設定值；此記憶是依瀏覽器各自儲存（不同使用者/裝置互不影響），且不受 Streamlit Cloud 容器重啟影響。清除瀏覽器資料或換瀏覽器/裝置開啟則會回到預設值。美股與台股的設定值各自獨立記憶（例如時間範圍、勝率、FCN 條款等），切換「市場」鍵不會互相覆蓋；「市場」鍵本身則不記憶，每次重新打開頁面一律預設回「美股」，避免不小心忘記目前在哪個市場、把代號打進錯誤分頁的情況。
- **台股名稱一律中文顯示**：不論是個股、ETF 成份股、買賣建議或存股區清單，台股代號皆會轉換為中文名稱顯示（來源依序為內建精選清單 → TWSE 上市公司名冊 → TWSE ETF 名冊 → TPEx 上櫃報價 API），涵蓋上市、上櫃與 ETF，查無資料才會退回顯示 Yahoo Finance 的英文名稱。
- **資料品質防呆**：抓價函式會過濾掉「當天市場尚未收盤、還在跳動的盤中未確認 K 棒」（依台股 13:30 / 美股 16:00 的實際收盤時間判斷）以及收盤價為 NaN 的異常資料，改用上一個已確認收盤的交易日，避免最新收盤價、技術指標與買賣建議在盤中被半根 K 棒污染。

## 安裝與執行

```bash
pip install -r requirements.txt
streamlit run app.py
```

各分頁的時間範圍、比較代號、勝率與建議買賣標的數量皆為各分頁內各自的欄位（彼此獨立）。美股模式下，「多股比較、相關性與風險統計」分頁的比較代號欄位留空則代表「全部」，會自動帶入 S&P 500 全部成分股（清單即時從 Wikipedia 抓取，若無網路則退回一份內建的知名成分股清單）；標的數量較多時，比較圖表會自動裁切前 30 檔以維持可讀性與效能，風險統計表則仍處理全部標的。台股模式下留空則代表內建台股觀察清單（含 ETF 及個股）。

## 部署到 Streamlit Community Cloud（免費，分享給他人）

部署後會得到一個公開網址（例如 `https://你的app名稱.streamlit.app`），任何人點連結即可使用，不需安裝任何東西。

1. 確認程式碼已推送到 GitHub（`app.py`、`requirements.txt`、`.streamlit/config.toml` 都在 repo 內）。
2. 前往 [share.streamlit.io](https://share.streamlit.io)，用 GitHub 帳號登入並授權。
3. 點 **Create app** → **Deploy a public app from GitHub**。
4. 填入：
   - **Repository**：`你的帳號/0518test`
   - **Branch**：要部署的分支（例如 `main`）
   - **Main file path**：`app.py`
5. 點 **Deploy**，等待約 1～3 分鐘安裝相依套件並啟動。
6. 完成後即可分享網址。之後每次 push 到該分支，App 會自動重新部署為最新版。

> 本專案已內含 `.streamlit/config.toml`，部署時會自動套用主題與伺服器設定，無需額外調整。
> Community Cloud 的對外網路可正常連線 Yahoo Finance，因此線上版能抓取真實股價資料。

## 專案結構

```
app.py                      # Streamlit 主程式（市場焦點／個股資訊／買賣建議／存股區／FCN風險評估／多股比較六個分頁）
.streamlit/config.toml      # 主題與伺服器設定（部署時自動套用）
requirements.txt            # Python 相依套件
src/data_loader.py          # yfinance 資料存取（含快取、盤中未收盤K棒／NaN收盤價防呆）
src/price_fetch.py          # yfinance 失效時的備援：直接打 Yahoo chart REST 端點
src/technical.py            # 技術指標計算（SMA/EMA/RSI/MACD/Bollinger）
src/risk.py                 # 風險與統計指標計算
src/recommend.py            # 買賣建議／存股區綜合評分計算
src/backtest.py             # 因子權重的 Rank IC 訓練與樣本外回測（供 train_weights.py 使用）
src/news.py                 # 中文新聞抓取（Google News RSS）與關鍵字情緒分析
src/universe.py             # S&P 500/美股觀察名單與台股（個股+ETF，含上市+上櫃）觀察清單、中文名稱對照
src/fcn.py                  # FCN 蒙地卡羅定價／風險模擬引擎
src/fcn_records.py          # FCN 實單紀錄與校準用的歷史成交價比對
src/fcn_screen.py           # FCN 標的組合篩選邏輯
train_weights.py            # 選用維護腳本：重新訓練買賣建議因子權重（見下方說明）
trained_weights.json        # train_weights.py 套用後寫入的權重覆蓋層（git 追蹤，可 diff/revert）
```

### 選用維護腳本：`train_weights.py`

用歷史資料重新訓練買賣建議的因子權重（Rank IC 目標），跟目前手調權重做樣本外比較，只有訓練後打贏現行權重才會詢問是否套用；不需要日常操作，App 平時運作不依賴它。

```bash
python train_weights.py --market tw --years 5
python train_weights.py --market us --years 5 --max-tickers 120
```

`--market` 為必填（`tw` 或 `us`，兩市場分開訓練互不覆蓋）。跑完會印出各 horizon（short/medium；long 因歷史樣本不足不訓練）的訓練前/後權重比較，若有勝出的 horizon 會詢問是否套用（y/N），確認後才寫入 `trained_weights.json`；`src/recommend.py` 的 `weights_for()` 會在下次執行時自動疊加套用，不需要重新部署或改程式碼。
